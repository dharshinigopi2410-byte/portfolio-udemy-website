# Udemy Course Card Clone

A pixel-perfect, fully responsive clone of the **Udemy Course Card** component. This project focuses on clean semantic HTML structure and modern CSS styling techniques to recreate the exact look and feel of the Udemy marketplace cards.

## 🚀 Live Demo
[git clone https://github.com]

## ✨ Features
* **Semantic HTML5:** Structured using meaningful tags for accessibility.
* **Modern CSS Layouts:** Built using Flexbox/Grid for alignment and spacing.
* **Hover Effects:** Smooth transitions on card hover, matching the original platform's behavior.
* **Responsive Design:** Adapts seamlessly across desktop, tablet, and mobile screens.
* **Custom Typography & Icons:** Implemented clean fonts and star rating iconography.

## 🛠️ Tech Stack
* HTML5
* CSS3 (Custom Variables, Flexbox)
